# Changelog

One line per release. GHL embeds reference these tags.

## v1.2.0
- HOA Track Two repriced: $650 minimum now covers 10 units (was 24), matching Track One. Starter rate $12.75 for units 11–24 (19 units = $765), then $16 / $15 / $14. Associations of 60+ units drop 2–9% vs v1.1.0; 11–59 units rise.
- Fee copy no longer says rates "step down as the community grows" (no longer true for Track Two).
- Calculator rate line now names the band, e.g. "$16 per unit for units 25–60".

## v1.1.0
- Add `app/hoa-pricing/` — HOA scope ledger, fee calculator, and schedule of fees moved out of GHL into the repo. All prices now in `config.js`.
- HOA calculator range label now reads from config ("4 — 200 units · larger communities by proposal"); previous "200+" label was unreachable.

## v1.0.0
- Initial public release of the UI kit.
