# Site shell

Sitewide header, footer, breadcrumbs and page components for brichausgroup.com on GHL.
Built to the *Master SEO and Navigation Architecture* plan (Sections 2–4).

| File | What it holds | GHL placement |
|---|---|---|
| `header.html` | Logo, menu (desktop mega-menu + mobile accordion), Schedule button, skip link. Loads fonts, `shell.css`, `shell.js` | Custom HTML in the **global header section** |
| `footer.html` | Four link columns, license line, legal links | Custom HTML in the **global footer section** |
| `shell.css` | All shell + `.bh-page` component styles | loaded by `header.html` |
| `shell.js` | Dropdowns, mobile menu, focus handling, `aria-current`, contact-form business-line capture | loaded by `header.html` |

Page bodies live in `../site-pages/`. Each file's top comment holds its GHL path, SEO title,
meta description and canonical.

## Rules

- **Links are plain `<a href>` in the HTML**, never generated by script, so crawlers see them without running JS. `shell.js` only adds behaviour.
- **Publishing rule:** a link goes in the menu, footer or cross-link module only once its page is live. Future links sit in the HTML as `STAGE 2` / `STAGE 3` comments, ready to un-comment.
- **One CTA label everywhere:** *Schedule a Conversation* → `/contact`. GTM's `cta_click` trigger matches that link text, so don't reword it.
- **No trailing slashes** in any internal link (HighLevel treats `/x` and `/x/` as different pages).
- Breakpoint: below 1024 px the menu becomes the mobile drawer.
